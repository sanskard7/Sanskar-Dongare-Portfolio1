## Preview locally

Extract the ZIP and open `index.html` in a modern browser, or open the folder in VS Code and use Live Server.

## Publish to your existing GitHub repository

1. Extract the ZIP.
2. Upload/replace `index.html`, `css/style.css`, `js/script.js`, and `README.md` in your existing repository. Keep the folders and paths exactly as shown.
3. Commit the changes.
4. Wait for GitHub Pages to deploy, then refresh the published page with `Ctrl + F5`.
